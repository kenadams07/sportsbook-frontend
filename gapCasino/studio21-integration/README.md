# Studio 21 Integration API Implementation

This folder contains a separate implementation of the Studio 21 Integration API based on the specifications in the PDF document.

## Structure

- `src/` - Main source code
- `entities/` - Database entities
- `controllers/` - API controllers
- `services/` - Business logic services
- `dto/` - Data transfer objects
- `utils/` - Utility functions
- `config/` - Configuration files

## Implementation Notes

This implementation is completely separate from the existing gapCasino implementation and follows the Studio 21 API specifications exactly as outlined in the PDF document.
